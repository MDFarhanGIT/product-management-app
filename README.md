# product-management-app
This project is a web-based product management system where users can manage a product catalog end to end. From the browser, a user can add new products, edit existing details, delete products no longer needed, and search the catalog to find items quickly. The frontend handles the user interface and form interactions, the backend processes requests and applies the business logic, and the database stores all product data persistently. SQLAlchemy is used as the ORM layer, mapping Python classes to database tables so the app can run queries and updates without hand-written SQL.
